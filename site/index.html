RFGlauncher

Ein einzelnes, selbstständiges Programm. Keine zusätzliche Laufzeit nötig – einfach herunterladen, entpacken und starten. Der Launcher prüft beim Start selbstständig auf neue Versionen.

Jetzt herunterladen (.exe)

Windows-SmartScreen kann beim ersten Start einen Hinweis zeigen – die Datei stammt direkt aus dem offiziellen GitHub-Release.

Installation in 3 Schritten

  1. HerunterladenLink oben anklicken – die .exe wird gespeichert.
  2. EntpackenDen Download entpacken und den Ordner frei wählen.
  3. StartenRFGlauncher.exe öffnen, Spielstart bestätigen.

Systemvoraussetzungen

  • Windows 10 oder 11, 64-Bit
  • 4 GB RAM
  • ~1 GB freier Speicher
  • Internetzugang für Updates
